# Установка на Windows 10/11 x64

Whisper, модели распознавания, CUDA, Docker и WSL не требуются.

1. Скачайте ZIP через **Code → Download ZIP** в репозитории GitHub и распакуйте
   в постоянную папку, например `C:\Programs\video-downloader`.
   Или выполните `git clone https://github.com/romolego/video-downloader.git`.
2. Нужен Python 3.11+. Если его нет, установщик попробует установить Python
   через winget. При ручной установке с python.org включите **Add Python to PATH**.
3. Запустите **Установить загрузчик.bat**. Установщик создаст `.venv`, установит
   Python-зависимости и при необходимости FFmpeg и Node.js через winget.
4. Запустите **Запустить загрузчик.bat**. Интерфейс: <http://127.0.0.1:8877>.
5. Нажмите **Скачать по ссылке**, вставьте ссылку RuTube, проверьте её,
   выберите видео или аудио, качество и проект. Добавьте запись в очередь.

При запросе Windows разрешите установку необходимых системных компонентов.
Если winget недоступен, установите вручную Python 3.11+, Node.js 22+ и FFmpeg
с FFprobe, добавьте их в PATH и повторите установку.

Для запуска агентом или из терминала без паузы BAT:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/install.ps1 -Plan
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/install.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/start.ps1 -NoBrowser
```

**Проверить загрузчик.bat** проверяет установленные компоненты.
**Обновить загрузчик.bat** обновляет модуль скачивания yt-dlp и его EJS-компонент.
Для обновления самого исходного кода остановите загрузчик и выполните `git pull`
либо замените исходные файлы из нового ZIP, сохранив `data` и `downloads`.
Установщик останавливает работающий сервис до изменения библиотек.

Настройки, проекты и состояния докачки находятся в `data` и `downloads`.
В GitHub их нет: новая установка начинает с пустой библиотеки.
Cookies и пароли доступа добавляются только локально.

YouTube может требовать VPN для всего компьютера, собственный прокси или cookies.
Обычное расширение VPN в браузере не меняет подключение загрузчика. RuTube,
VK, Яндекс.Диск и Google Drive проверяются своим подключением к источнику.
Приватные, удалённые и ограниченные записи требуют доступа у самого источника.
