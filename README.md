# Локальный загрузчик видео и аудио

Самостоятельный сервис, выделенный из модуля скачивания Whisper Studio.
Whisper, модели распознавания,
видеокарта и его сервер для работы не нужны.

## Запуск

Установка из GitHub на другой компьютер: [пошаговая инструкция](INSTALL.md).

1. На новой машине запустите **Установить загрузчик.bat**.
2. Запустите **Запустить загрузчик.bat**. Откроется <http://127.0.0.1:8877>.
3. Нажмите **Скачать по ссылке**, вставьте ссылку, проверьте её, выберите
   видео или только аудио, качество и проект. Добавьте запись в очередь.

**Остановить загрузчик.bat** или кнопка **Остановить** в интерфейсе завершают
сервис с сохранением недокачанных файлов. При следующем запуске активные
загрузки продолжаются автоматически. Загрузки, которые вы сами поставили
на паузу, остаются на паузе до нажатия **Продолжить**.

**Обновить загрузчик.bat** корректно останавливает сервис, обновляет
`yt-dlp[default]` вместе с совместимым EJS-компонентом и запускает сервис снова.
Настройки, проекты и частичные файлы сохраняются. **Проверить загрузчик.bat**
показывает наличие Python-зависимостей, FFmpeg/FFprobe и JavaScript-движка.

Новые проекты загрузчика независимы от библиотеки Whisper.

## Возможности

- Источники: публичные ссылки YouTube, RuTube, VK / VK Video,
  Яндекс.Диска, Google Drive и записи Zoom с кодом доступа.
- Метаданные перед скачиванием: название, автор, длительность, доступные
  разрешения, доступность звука для каждого качества и ориентировочные размеры.
- Видео со звуком либо оригинальная аудиодорожка. Если отдельного аудио нет,
  скачивается совмещённый файл и видеоряд удаляется FFmpeg без перекодирования
  звука. Контейнер выбирается по кодеку.
- Для видео при том же разрешении предпочтительны H.264 и AAC. После сборки
  FFprobe проверяет обе дорожки и их длительность; файл без звука не получает
  статус «Готово». При необходимости звук переводится в AAC для MP4, видеоряд
  сохраняется без перекодирования. Проверенный звук отмечается в карточке записи.
- Автовыбор по настройкам; ручной выбор доступного разрешения; максимум.
  Если нужного разрешения нет, выбирается ближайшее не выше заданного, а
  если все выше — самое низкое доступное. Уже добавленное качество фиксируется
  и не меняется при редактировании настроек.
- Несколько записей в одном проекте, создание пустых проектов,
  переименование, папки проектов, перенос, поиск, фильтры, общая лента
  или группы по папкам, массовый перенос и удаление выбранных проектов.
- Создание проекта и новой папки прямо в форме скачивания: введённая ссылка,
  выбранный режим и качество сохраняются, новая папка сразу выбирается.
- Единая сохраняемая очередь; от одной до четырёх одновременных загрузок.
  Прогресс, скорость, оставшееся время, повторные соединения и понятные ошибки.
- Пауза и докачка, автоматические повторы при сетевых сбоях,
  восстановление активной очереди после перезапуска.
- Отмена удаляет частичные файлы данной загрузки. Готовую запись или проект
  можно убрать только из библиотеки, оставив файлы, либо удалить с файлами.
  Выполняющуюся загрузку сначала нужно поставить на паузу или отменить.
- Просмотр готовой записи в браузере, сохранение копии и открытие папки в
  проводнике. Воспроизведение зависит от поддержки кодека браузером.
- Независимые настройки: режим, качество видео, параллельность, путь новых
  проектов, имена, вид библиотеки, cookies YouTube, светлая и тёмная темы.

Папки в интерфейсе группируют проекты. Переименование и перенос по папкам
не меняют физические пути, поэтому текущие загрузки и докачка сохраняются.
Изменение корневой папки применяется к новым проектам; старые остаются на месте.
При сохранении копии первоначальный файл остаётся в проекте.

## YouTube и ограничения источников

Сервис перебирает способы обращения к YouTube и отдельно запоминает удачные
для метаданных и скачивания. Явно подключает установленный Node.js;
Deno также поддерживается yt-dlp. Нужны актуальные yt-dlp и
совместимый `yt-dlp-ejs`: они устанавливаются и обновляются вместе.
Основание: [официальная инструкция EJS](https://github.com/yt-dlp/yt-dlp/wiki/EJS).

Перебор помогает при некоторых бот-проверках и ответах 403, но источник может
по-прежнему требовать вход, cookies или ограничить доступ. Если YouTube
отказывает, обновите загрузчик; при необходимости положите Netscape-файл
`cookies.txt` в **Настройки → Открыть папку cookies** либо выберите браузер
с нужной сессией. Cookies браузера по умолчанию выключены. Доступность чтения
зависит от защиты браузера. Cookies — личные данные входа, их не следует
передавать вместе с исходным кодом.

Докачка зависит от сервера: для HTTP-файлов используется Range, для
фрагментированных записей — сохранённые фрагменты и состояние yt-dlp.
Если источник перестал отдавать прежний файл, продолжение может потребовать
повторной загрузки. Плейлисты намеренно не раскрываются: одна добавленная
ссылка — одна запись, как в исходном модуле.

В **Настройки → Подключение к YouTube** можно выбрать прямое соединение
либо свой HTTP/HTTPS/SOCKS-прокси. Это подключение применяется к метаданным,
видео, аудио и докачке. Можно также использовать VPN для всего компьютера.
VPN-расширение только в браузере само по себе не меняет соединение загрузчика.
Ответ «Video unavailable» теперь уточняется другими клиентами; при известной
блокировке показывается причина, а приватные и удалённые записи не перебираются.

## Хранение и перенос

- `data/library.sqlite3`: проекты, папки, настройки и идентификаторы загрузок.
- `downloads/`: проекты и их записи; другую папку можно выбрать в настройках.
- `url_download.json`, `.part`, `.ytdl` возле записи: состояние докачки.
- `data/cookies/`: cookies и инструкция.
- `logs/`: журнал сервиса.
- `downloader/`: независимое ядро и HTTP API; `web/`: интерфейс;
  `scripts/`: запуск, установка, обновление и проверка; `tests/`: проверки.

Для резервной копии сначала остановите сервис, затем сохраните каталог
проекта и внешние папки загрузок, если они настроены. На другом компьютере
нужно переустановить окружение через установщик; `.venv` не переносится.
База и состояния содержат абсолютные пути: существующую библиотеку переносите
с сохранением путей. Автоматическое изменение путей старой библиотеки
в этой версии не реализовано. Для передачи только кода исключите `.venv`,
`data`, `downloads`, `logs`, `run` и пользовательские cookies.

## Использование в других проектах

Другие приложения могут использовать этот сервис по HTTP, без запуска Whisper:

```python
import requests

base = "http://127.0.0.1:8877/api"
headers = {"X-Downloader-Client": "local"}
result = requests.post(
    base + "/downloads", headers=headers,
    json={"url": "https://youtu.be/VIDEO_ID", "quality": "720",
          "project_name": "Мой проект"}, timeout=180,
)
result.raise_for_status()
download_id = result.json()["id"]
library = requests.get(base + "/library", timeout=10).json()
```

Передайте `project_id` существующего проекта, чтобы добавить запись в него.
`quality` принимает `auto`, `audio`, `max` или разрешение числом в строке.
`auto` следует сохранённому режиму и качеству. Явное число означает видео,
`audio` — только аудио. Zoom принимает `passcode`; он сохраняется локально
для докачки, но не выдаётся в ответах API.

Основные маршруты:

| Маршрут | Назначение |
| --- | --- |
| `GET /api/library` | Проекты, папки, загрузки, настройки |
| `POST /api/probe` | Метаданные ссылки и качества |
| `POST /api/downloads` | Добавить загрузку в новый или существующий проект |
| `POST /api/downloads/{id}/pause` | Пауза |
| `POST /api/downloads/{id}/resume` | Продолжить |
| `POST /api/downloads/{id}/cancel` | Отмена с очисткой частичных файлов |
| `GET /api/downloads/{id}/file` | Готовый файл для сохранения |
| `PUT /api/settings` | Изменить настройки |
| `GET /api/health` | Диагностика компонентов |

Полная схема API: <http://127.0.0.1:8877/docs>. Запись требует заголовка
`X-Downloader-Client: local`. Сервер слушает только `127.0.0.1`; запросы записи
с другой веб-страницы блокируются. Другую локальную программу подключайте
через HTTP-клиент.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
node --check web\app.js
```

Проверки используют временные библиотеки и не меняют пользовательские проекты.
Включены реальные yt-dlp HTTP-загрузка и продолжение через Range после паузы
с чтением сохранённого состояния, проверка хеша итогового файла, настоящее
извлечение аудио через FFmpeg и проверки очереди/API.

Происхождение ядра: `backend/video_downloader.py`, `backend/youtube_access.py`
и `backend/zoom_access.py` из локального Whisper Studio, выделены 9 октября
2026 года. Модули проектов/хранения/API и интерфейс адаптированы для
самостоятельной работы; исходный код Whisper не изменён.
